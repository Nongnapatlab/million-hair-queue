อัปเดตโค้ด Apps Script

  1. บน Mac พิมพ์ใน Claude Code: ! pbcopy < ~/Downloads/million-hair-queue/apps-script/Code.gs
  2. เปิด Apps Script → คลิกช่องโค้ด → Cmd + A → Cmd + V → Cmd + S
  3. เลือกฟังก์ชัน setup → ▶ Run
  4. Deploy → Manage deployments → ✏️ → Version: New version → Deploy (ห้ามกด New deployment)

เพิ่มแอดมิน (เพื่อนในทีม)

  1. ให้เพื่อนเปิดหน้านี้แล้วล็อกอิน LINE จะเห็น User ID (ขึ้นต้นด้วย U…)
  2. Apps Script → ⚙️ Project Settings → Script properties → ADMIN_USER_IDS
  3. ต่อท้ายด้วยเครื่องหมายจุลภาค เช่น Uaaa,Ubbb → Save (ไม่ต้อง Deploy ใหม่)
  4. แชร์ Google Sheet (Editor) และเพิ่มเพื่อนใน OA Manager → ตั้งค่า → สิทธิ์การเข้าถึง

เช็กลิสต์ทดสอบระบบ

  1. จองจาก LINE (ไม่แนบสลิป) → ได้ข้อความ “ได้รับคำขอจอง”
  2. ตารางนัด → กดนัด → “รับมัดจำแล้ว · ยืนยันนัด” → ลูกค้าได้ Flex ยืนยัน
  3. กด มาถึงแล้ว → เริ่มบริการ → เสร็จสิ้น → ขึ้น “+แต้ม”
  4. LINE → MY BOOKING → แต้มสะสม → เห็นแต้มและเลขสมาชิก
  5. พิมพ์ “ราคา” ในแชต → ได้ตารางราคา

สคริปต์เดโม 5 นาที

  1. เปิดแชต Million Hair บนมือถือ (ฉายจอ) → โชว์ rich menu
  2. BOOK NOW → เลือกความยาวผม + บริการ → ช่าง → วัน-เวลา → รายละเอียด → ยืนยัน
  3. สลับไปหลังบ้าน → นัดเด้งในตารางของช่าง → รับมัดจำ → Flex เด้งในแชต
  4. กดเสร็จสิ้น → เปิด POINTS ให้เห็นแต้มเพิ่ม
  5. ปิดด้วยหน้ารายงาน: no-show, การใช้เก้าอี้, ความพึงพอใจ
